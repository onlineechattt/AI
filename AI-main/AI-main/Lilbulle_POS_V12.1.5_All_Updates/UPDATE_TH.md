## อัปโหลดครั้งเดียว
1. แตก ZIP นี้ แล้วเปิด GitHub onlineechattt/AI ที่หน้าแรกของ repository
2. Add file → Upload files → ลากโฟลเดอร์ public จากชุดนี้ลงหน้าอัปโหลด
3. ตรวจว่ามี public/app.js, public/index.html, public/bundles.js และ public/assets/payment-qr-original.jpeg
4. ต้องไม่เป็น public/public และไม่ลบไฟล์อื่นในโปรเจกต์
5. Commit ครั้งเดียว รอ Netlify แสดง Published แล้วกด Ctrl+Shift+R ที่เว็บ
6. เปิดจัดการ ตรวจเว็บ V12.1.5; หลังบ้าน V12.1.2 รองรับโดยตั้งใจ

## ใช้ QR อย่างไร
เลือกสินค้า → กรอกราคาให้ยอดมากกว่า 0 → เลือกเงินโอน → กด “แสดง QR รับเงิน”
เลือกเงินโอนอย่างเดียวจะแสดงปุ่ม ไม่เด้งหน้าต่างเอง
QR เป็นภาพเดิม ยอดบนเว็บเป็นข้อความกำกับ ไม่ได้ฝังยอดใน QR อัตโนมัติ
ลูกค้าต้องกรอก/ตรวจยอดในแอปธนาคาร ทีมงานตรวจเงินเข้าก่อนกดยืนยันรับเงิน
การเปิด QR ไม่บันทึกขายหรือยืนยันการรับเงินจริงอัตโนมัติ
ก่อนใช้กับลูกค้า ให้สแกนตรวจชื่อผู้รับและความชัดด้วยแอปธนาคาร เพราะยังไม่ได้ทดสอบสแกนจริง

## สถานะตรวจ
ทดสอบจำลองการบันทึก/รีเฟรชล้มเหลว/คงคำขอเดิม/QR ผ่าน และตรวจไวยากรณ์ JavaScript
ยังไม่ได้ทดสอบหน้าเว็บในเบราว์เซอร์จริงหรือแอปธนาคาร ยังไม่ได้ติดตั้งบนเว็บจริงโดยผู้ช่วย
ความเร็วบันทึกยังขึ้นกับ Apps Script และเครือข่าย ไม่ได้รับรองว่าเร็วขึ้นทุกขั้นตอน
